# E-Commerce Sales Analysis using MySQL
 
## 📊 Project Overview
Analyzed E-Commerce sales data using MySQL to extract 7 key business insights for decision making.
 
## 🔍 Key Insights
1.  **Top 7 Products by Quantity** - Best selling products
2.  **Monthly Sales Revenue** - Revenue trend analysis
3.  **Top 5 Customers by Spending** - High value customers
4.  **City-Wise Orders** - Patna has highest orders
5.  **Average Order Value** - ₹75,200
6.  **Inactive Customers** - Customers with no orders
7.  **Revenue by Category** - Electronics is top category
